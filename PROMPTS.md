# PROMPTS.md — Промпты для Claude Design

Составлены на основе `DESIGN.md`. Объём: только экраны интерфейса (иконка/сплэш — отдельная будущая задача). Реализуемость в коде заранее не ограничивается — сначала оцениваем лучший возможный дизайн, вопрос «что из этого реализовать и как» решается отдельно после просмотра результатов.

## Базовый промпт

```
Отредизайни визуальный язык дневника тренировок для Flutter-приложения (Material 3, Android/iOS, обязательны светлая и тёмная темы). Цель — из функционального, но безликого интерфейса сделать современный, энергичный, спортивный дизайн с чёткой визуальной иерархией — не просто «покрасить», а перестроить структуру внимания.

Аудитория: тренирующиеся в зале, часто одной рукой, между подходами, с потными руками — крупные тач-зоны, минимум текста для чтения, мгновенно считываемые числа и таймеры.

Ключевой экран — редактор тренировки в статусе «Выполняется»: карточки упражнений со строками подходов (план и факт по весу/повторениям), чекбокс «выполнено», бегущий таймер тренировки и таймер отдыха между подходами. Сейчас план и факт неразличимы (два одинаковых пустых поля без подписи), чекбокс «выполнено» и кнопка удаления подхода — одинакового размера впритык друг к другу (риск промаха потным пальцем), оба таймера визуально не выделены среди обычного текста. Реши именно это в первую очередь.

Другие экраны: список тренировок с цветными статус-чипами (6 статусов сейчас неразличимы), монотонный список из 199 упражнений без визуальной дифференциации, статистика с графиками, где ключевые числа не выделены среди подписей, экран-итог тренировки с новыми личными рекордами — сейчас подан нейтрально, как настройки, хотя это единственное место для эмоционального акцента.

Текущая система: единственный заданный цвет — сид #4C7BD9 (Material 3 tonal palette, вся остальная палитра сгенерирована алгоритмически); типографики, spacing-шкалы и кастомных компонентов нет вообще — можно предложить всё заново. Сохрани структуру нижней навигации из 5 вкладок (Сегодня/История/Упражнения/Статистика/Ещё).
```

## Вариации направлений

Прогонять по очереди, дописывая блок направления в конец базового промпта — так все варианты сравниваются на одной контентной основе.

**А — смелый/контрастный:**
```
Направление А — смело и контрастно: крупные цветовые блоки, высокий контраст тёмного фона и ярких акцентов, статус-чипы и таймеры — с насыщенным цветовым кодированием (не просто оттенок текста, а заливка/обводка), типографика с крупными жирными цифрами для ключевых метрик. Не бойся визуального веса — это должно «кричать» на бегу, а не шептать.
```

**Б — консервативный/строгий:**
```
Направление Б — сдержанно и строго: минимум цвета сверх необходимого для считываемости (статус, план/факт, ошибка), приглушённая профессиональная палитра, акцент на чистоте сетки и воздухе между блоками, а не на ярких акцентах. Ближе к премиальному спортивному бренду, чем к ярким фитнес-приложениям.
```

**В — геймификация/мотивация:**
```
Направление В — с акцентом на геймификацию: экран-итог тренировки и новые рекорды получают выраженный «момент праздника» (цвет, иконография, возможно лёгкий анимационный намёк), элементы прогресса и вознаграждения по всему приложению (полоски прогресса, значки достижений), но без превращения в казуальную игру — тренировки должны оставаться серьёзным инструментом.
```

**Г — индустриально-спортивный:**
```
Направление Г — индустриально-спортивное: язык спортивной экипировки/трекеров (Garmin, Whoop, таймеры кроссфита) — техническая типографика, высококонтрастные сигнальные цвета, крупные монолитные цифры таймеров, минимум декоративных элементов — всё функционально и «по делу».
```
