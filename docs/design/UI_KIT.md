Владелец прислал в чат скриншот UI-kit сводки (цвет/типографика/отступы/чипы/кнопки/таймер отдыха) — судя по формату, это выдержка из заметок по дизайн-системе в самом HTML-макете Claude Design (см. `NEEDED_FROM_USER.md`/CLAUDE.md: «макет... с заметками по дизайн-системе прямо в нём»). Файл самого макета в репозитории не хранится; этот документ фиксирует содержимое скриншота текстом и сверяет его с тем, что реально реализовано в коде на момент написания (после Фазы 2, все 8 экранов).

Сам файл — **`ui_kit_reference.png`** (в этой же папке; положен владельцем вручную 2026-07-26, так как у ИИ-исполнителя нет доступа к файлам, вложенным в чат, без явно переданного пути).

## 4. Открытые расхождения (не исправлялись самостоятельно — нужно решение владельца)

Ничего из этого не менялось в коде по итогам скриншота — только зафиксировано для будущего решения, по тому же принципу, что и весь проект («не изобретать, спрашивать»).

1. **Цвет статуса «Отменена»/«Пропущена» не совпадает с референсом.** Скриншот показывает `Error` (красный) = «пропущена», `Warning` (золотой) = «отменена». Реализация (`workoutStatusColors()`, `lib/app/design_tokens.dart`) делает наоборот: `skipped` → `scheme.tertiary` (не error), `cancelled` → `scheme.error` (красный, не отдельный warning-жёлтый). Отдельного токена `warning`/`AppSemanticColors` для золотого цвета в проекте нет вообще. Не факт, что скриншот — актуальная версия семантики (может быть более ранняя итерация макета); нужно отдельно уточнять у владельца, стоит ли: (а) добавлять четвёртое семейство цветов `warning`, (б) менять текущее сопоставление статус→цвет.
2. **Статус «Просрочена» отсутствует в доменной модели.** `WorkoutStatus` (DM 6.4.1) — это `draft/planned/inProgress/completed/skipped/cancelled`, шести значений, без понятия «просрочена». Скриншот показывает 6 чипов, но один из них — статус, которого не существует в схеме. Похоже на общий референс-набор дизайн-системы (не привязанный к нашей точной доменной модели), а не на пропущенную функциональность — никаких изменений схемы не предлагается без явного запроса.
3. **Нет отдельного текстового стиля «Label, caps».** Скриншот показывает подписи вроде «ПЛАН»/«ФАКТ» заглавными буквами как отдельную типографическую роль. В коде (`l10n.setColumnPlan` = «План», без `.toUpperCase()`/letterSpacing) подписи выводятся как есть, без этого стиля. Мелкая, чисто косметическая недостача — не стал добавлять самостоятельно, так как заглавные подписи взаимодействуют с локализацией (регистр в RU/EN) по-разному и это осознанная стилевая правка, а не однозначный баг.
4. **Форма чекбокса «выполнено».** Скриншот показывает скруглённый квадрат (squircle); в `SetRow`/`ExpandableSetRow` реализован круг (`CircleBorder()`). Это уже осознанный, протестированный выбор из Фазы 2/экран 1 — упоминаю только для полноты сверки, менять не предлагаю.
5. **Шкала отступов не содержит 20.** `AppSpacing` (`lib/app/design_tokens.dart`): `xs=4, sm=8, md=12, lg=16, xl=24, xxl=32` — совпадает со скриншотом, кроме значения 20, которого в шкале нет. На практике 20 нигде явно не понадобилось (16/24 достаточно везде, где применялась шкала) — не добавлял ради значения, для которого нет использования.

## 5. Что подтверждено 1:1

- Кнопки: «Основная» (`FilledButton`) / «Вторичная» (`OutlinedButton`) — без расхождений.
- Таймер отдыха с заливкой-прогрессом внутри пилюли (оранжевый фон + светлая заливка остатка) — реализовано в `RestTimerCard` (`lib/core/widgets/rest_timer_card.dart`), тот же визуальный принцип.
- Минимальный тач-таргет 48dp для интерактивных элементов — общее правило проекта (UX 11), соблюдается во всех местах, тронутых редизайном.
