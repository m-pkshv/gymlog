IronBook Privacy Policy

Effective date: August 8, 2026

IronBook is a workout diary app. It is built to never collect or transmit user data outside the device.

What data the app stores

Everything you enter in IronBook (workouts, exercises, sets, templates, body measurements, tags, your profile name/nickname and photo) is stored exclusively on your device, in the app's private database. The app has no server and never sends this data anywhere automatically.

Export and backups

The "CSV export", "PDF export", and "Backup" features build a file and hand it to your device's standard system "Share" sheet. Where that file goes (a messaging app, email, cloud storage, etc.) is entirely your choice at the moment you share it; the app itself never sends the file anywhere and has no access to it afterward.

Device permissions

  • Notifications — used only to remind you when the rest timer between sets ends.
  • Camera (optional) — used only for a profile photo you take and save locally yourself; only triggered when you explicitly tap "Take photo."
  • Photo/file access — only opened when you pick a profile photo or a backup file to restore, via the system file picker; the app does not get access to your whole gallery or storage.

Analytics, ads, third parties

The app contains no ads, no analytics, no tracking, and shares no data with third parties. It works fully offline.

Data deletion

All data is deleted when you uninstall the app. Individual records (workouts, exercises, measurements, etc.) can be deleted inside the app at any time.

Contact

Questions about this policy: ironbook.dev@gmail.com

Политика конфиденциальности IronBook

Дата вступления в силу: 8 августа 2026 г.

IronBook — приложение-дневник тренировок. Оно разработано так, чтобы не собирать и не передавать никакие данные пользователя за пределы его устройства.

Какие данные хранит приложение

Все данные, которые вы вводите в IronBook (тренировки, упражнения, подходы, шаблоны, замеры тела, теги, имя/никнейм и фотография в профиле), хранятся исключительно локально на вашем устройстве, в закрытой базе данных приложения. Приложение не имеет сервера и не отправляет эти данные никуда автоматически.

Экспорт и резервные копии

Функции «Экспорт CSV», «Экспорт в PDF» и «Резервная копия» формируют файл и передают его через стандартное системное окно «Поделиться» вашего устройства. Куда именно уйдёт этот файл (в мессенджер, почту, облачное хранилище и т.п.) — решаете только вы в момент отправки; само приложение никуда файл не отправляет и не имеет к этому доступа после передачи.

Разрешения устройства

  • Уведомления — используются только для напоминания об окончании таймера отдыха между подходами тренировки.
  • Камера (по желанию) — используется только для фото профиля, которое вы сами делаете и сохраняете локально; работает только если вы явно нажали «Сделать фото».
  • Доступ к фото/файлам — открывается только когда вы сами выбираете фото для профиля или файл резервной копии для восстановления; в обоих случаях используется системное окно выбора файла, приложение не имеет доступа ко всей галерее/хранилищу целиком.

Аналитика, реклама, сторонние сервисы

Приложение не содержит рекламы, аналитики, средств отслеживания и не передаёт никакие данные третьим лицам. Оно работает полностью офлайн.

Удаление данных

Все данные удаляются вместе с удалением приложения с устройства. Отдельные записи (тренировки, упражнения, замеры и т.д.) можно удалить прямо в приложении в любой момент.

Контакты
